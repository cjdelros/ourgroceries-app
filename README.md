# OurGroceries macOS app

Native Swift implementation of a lightweight menubar client. The initial package contains the Phase 1 protocol adapter and a fixture-first developer harness. It uses a fixed HTTPS origin and an in-memory, per-session cookie store; no credential or cookie persistence exists in this package.

Live requests must only be tested with the designated test account and list. Do not provide credentials in issues, commits, or command-line arguments.
